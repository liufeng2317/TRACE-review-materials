# Ridgecrest Phase Picking

This stage applies PhaseNet to the validated waveform products from the
Ridgecrest production window.

The manuscript production workflow covered 4 July 2019 through 26 July 2019.
It retained 1,454,311 P arrivals and 1,641,210 S arrivals before the
30-station core subset was used for GaMMA association. Full daily pick tables,
waveforms, and model runtime outputs are not included in this release.

The entry script and trajectory record document the agent workflow. The
production counts above are the values reported in the manuscript
supplementary information; the compact GaMMA and HypoDD result files in the
next stages are the reviewable downstream products.
