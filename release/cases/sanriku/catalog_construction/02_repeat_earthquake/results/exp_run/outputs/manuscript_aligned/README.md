# Manuscript-Aligned Results

This directory contains the final repeating-earthquake result set used for the
manuscript-facing analysis.

The authoritative metadata file is
`manuscript_alignment_summary.json`. The corresponding CSV files are:

- `candidate_event_pairs.csv`
- `repeat_event_pairs.csv`
- `repeat_event_families.csv`
- `repeat_family_members.csv`

The analysis window is
`2025-11-01T00:00:00 <= origin_time < 2025-12-07T00:00:00`,
covering 2025-11-01 through 2025-12-06.

The summary records 19,726 event pairs, 783 pairs with
`median_cc >= 0.70`, 147 families, and 477 family members.
