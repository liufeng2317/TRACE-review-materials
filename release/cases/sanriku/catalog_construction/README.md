# Sanriku Catalog Construction

This release contains the code-facing workflow used to construct the Sanriku catalog and downstream products.

## Steps

- `00_catalog_download`: authenticated JMA catalog download, parsing, cleaning, and validation.
- `00_travel_time_download`: travel-time and phase-arrival data preparation.
- `01_relocation_HypoDD`: full-catalog HypoDD relocation and monthly time-window accounting.
- `02_repeat_earthquake`: repeating-earthquake analysis and manuscript-aligned post-processing.

Each step keeps its launcher script at the directory root. The corresponding `results/` directory follows the experiment-run layout:

- `results/exp_plans/`: planning and workflow records.
- `results/exp_run/`: run-specific analysis, scripts, reports, logs, and outputs.
- `results/log/`: overall run metadata and agent trajectories.
- `results/research_report/`: research reports and workflow descriptions.
- `results/state/`: resumable state and state history.

## Data and Access

The scripts use placeholders such as `<CASE_ROOT>`, `<REPO_ROOT>`,
`<WAVEFORM_DATA_ROOT>`, and `<HYPODD_ROOT>` for local data and software
locations. Credentials for authenticated services are supplied through the
user's local environment.

## Result Scope

The release contains validation products, native relocation outputs, and
manuscript-aligned repeating-earthquake tables together with the corresponding
plans, scripts, reports, logs, trajectories, and state records.

For the catalog handoff, the canonical expert-processed products are under
`00_travel_time_download/results/exp_run/expert/outputs/`. They contain
`33,702` events and the corresponding `picks.csv`, `phase.dat`, and
`station.sta` files used as the relocation input. The subsequent HypoDD
native HypoDD production output contains 25,648 rows. The validated,
manuscript-aligned relocation product is generated by the relocation expert
post-processing step and contains `25,646` events.
