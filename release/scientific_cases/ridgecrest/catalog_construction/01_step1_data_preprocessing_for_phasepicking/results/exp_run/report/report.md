# Ridgecrest Waveform Preprocessing

This stage prepares continuous SCEDC waveform data for PhaseNet picking and
Wood-Anderson amplitude measurement.

The manuscript production workflow covered 4 July 2019 through 26 July 2019,
with 47 selected three-component stations and 1,034 station-day jobs. After
quality control, 853 station-day waveform products were retained for the
catalog-construction route.

Raw waveforms and the full preprocessing products are not included in this
release. The entry script, selected QC tables, and trajectory record document
the agent workflow. The counts above are the production values reported in the
manuscript supplementary information.
